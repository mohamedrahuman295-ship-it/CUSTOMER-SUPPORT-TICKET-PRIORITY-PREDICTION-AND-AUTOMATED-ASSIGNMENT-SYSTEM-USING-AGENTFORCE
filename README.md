# Customer Support Ticket Priority Prediction and Automated Assignment System

## Overview

This project is a **Salesforce-based customer support automation system** developed using **Agentforce and Salesforce Flow**. It is designed to analyze customer support tickets, identify their priority, and automate appropriate support actions.

The system retrieves the latest support ticket associated with an account, analyzes the ticket description, classifies the ticket as **High, Medium, or Low priority**, and performs automated actions based on the identified priority.

## Key Features

* Support ticket analysis using Agentforce
* Priority classification into High, Medium, and Low
* Automated support-level assignment
* Automatic creation of urgent tasks for High-priority tickets
* SLA breach-risk checking
* Salesforce Flow-based workflow automation
* Agentforce action and subagent integration

## Technologies Used

* **Salesforce CRM**
* **Agentforce**
* **Salesforce Flow**
* **Salesforce Custom Objects**
* **Salesforce Tasks**

## Project Workflow

```text
Account Name
     ↓
Get Account
     ↓
Retrieve Latest Support Ticket
     ↓
Analyze Ticket Description
     ↓
Determine Priority
     ↓
Assign Support Level
     ↓
Create Urgent Task
     ↓
Check SLA Risk
     ↓
Final Response
```
